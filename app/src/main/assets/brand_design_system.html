Brand & Theme System
01 — Identity

A map-first identity. Monochrome ground, purposeful color.

Black-and-paper neutrals carry the interface. Color is never decorative — each hue is assigned one job: orientation, action, or alert. Nothing is styled "Orthodox" for its own sake; the restraint is the design.

03 — Typography

Space Grotesk + Inter + Plex Mono

A geometric display face gives the brand its edge, Inter carries all UI copy for maximum legibility, and a monospace face is reserved for data — distances, times, dates — so numbers read like instrumentation, not decoration. Ethiopic names get their own quiet typeface, never styled as calligraphy.

04 — Buttons

One accent, one meaning

Primary is always Ember. Route actions are always Teal. Nothing else borrows those colors, so a button's color alone tells you what it will do.

06 — Map Language

GPS dot, pins, and selection

A glowing teal dot marks the pilgrim. Default pins stay ink-neutral so the map isn't noisy; only a live event or a selected destination earns color.

07 — Iconography

One custom stroke system, every icon

24px grid, 1.75px stroke, rounded joins — same geometry as the Space Grotesk letterforms so icons and type feel drawn by the same hand. Nothing borrowed from a generic icon font; every mark below is a hand-built SVG path tied to the brand.
